Checking for firmware…

In Arduino IDE: Sketch → Export Compiled Binary with your board selected (this build targets an ILI9341-based ESP32 touch panel — a 2.4″ "CYD"-style board). Four files land next to your sketch, in a build/…/ folder. Select each one below; the flash offsets are pre-filled with the standard ESP32 defaults and rarely need changing.

Offsets don't match your build?

These four addresses are the standard layout for an ESP32 with the default 4 MB-flash, OTA-enabled partition scheme — true for almost every "ESP32 Dev Module" build. If yours differ, open Arduino IDE's File → Preferences → Show verbose output during: upload, upload once normally over USB, and read the exact esptool command it prints — each --flash_addr value there is the offset to enter above. The "Boot app0" file itself lives inside the ESP32 core, not your sketch folder — typically under Arduino15/packages/esp32/hardware/esp32/<version>/tools/partitions/boot_app0.bin.
